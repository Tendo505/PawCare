# PawCare project variants

## FYP: PawCareAI

The project in this root folder is the advanced final-year-project version. It contains:

- Kotlin Android application
- Laravel API in `backend/`
- PostgreSQL migrations and seed data
- Python FastAPI/TensorFlow service in `ai-service/`

## Mobile App Development: Java

The standalone `C:\\Users\\dozle\\StudioProjects\\PawCareMobileAppDev` project contains:

- Plain Java Swing source files with no package declarations
- Separate `JFrame` screens like the supplied classroom example
- No network API and no database
- `.txt` files for users, pets, vaccinations, medical records, and appointments
- `login.java` as the program entry point

The FYP is an Android Studio project. The Java Swing version is a Windows desktop
program and should be opened as a normal Java project in JCreator, IntelliJ IDEA,
NetBeans, or VS Code. It does not run on an Android emulator.
